## 2. 一句话定义

Dex AGENT 是一款面向 Agent 开发者的桌面 coding agent 工作台：选择工作区、创建会话、提交编码任务并看到助手回复，同时用 3D 图谱和执行流视图观察 Agent 的构成、思考与工作方式。

## 3. 核心命题

Agent 对开发者而言基本是黑箱——能工作，但看不清它由什么构成、为什么这样做、下一步会做什么。Dex AGENT 要把黑箱打开，变成可观察、可拆解、可扩展的对象。

## 4. 目标用户

- 主用户：正在使用插件式 Agent 运行时或类似框架开发 Agent 的工程师。
- 特征：熟悉命令行、了解 Agent 基本概念、能读懂 TypeScript。
- 次用户（v0.3+）：希望入门 Agent 开发的初学者；MVP 不服务。

## 5. 核心能力（公开可讲）

| 能力 | 事实 |
| --- | --- |
| 编码主循环 | 选择工作区、创建会话、发送 prompt、流式助手回复、失败重试 |
| 编码工具 | 文件读写与精确编辑、文件名/内容搜索、终端命令、Git status/diff/add/commit |
| 3D 架构图谱 | Cordis 插件树反射为节点与边；节点=插件，边=inject 依赖与运行时调用 |
| 图谱交互 | 缩放、旋转、平移、点击详情、搜索定位、聚焦子图、按类型过滤、视角/缩放记忆 |
| 实时更新 | 插件加载/卸载、状态变更增量更新，不触发全图重排 |
| 执行流 DAG | Turn → Step → Tool Call；Step 节点、Tool Call chip、失败向上传播、详情面板 |
| 时间线 | 按时间排列事件流，与 DAG 联动 |
| 时间旅行 | 回退到任意 Step 查看当时上下文，支持回放（v0.2） |
| 双视图联动 | L1 状态同步、L2 过滤联动、L3 空间导航 |
| 模型控制 | 多家模型适配器热插拔；至少覆盖 DeepSeek 与 OpenAI 兼容端点（公开页默认不写模型名） |
| 会话历史 | 历史会话、任务记录、只读回放、图谱快照导出 |
| 插件能力预览 | 插件启用/禁用/配置预览（v0.2 进行中） |
| 主题 | 暗色 / 浅色双主题，跟随系统或手动切换 |
| 布局 | 三栏可拖拽、可折叠、布局预设与持久化 |

## 6. 明确非目标

- 不替代专业 IDE；不追求 IDE 级编码效率竞争。
- 不做编辑器级 diff、LSP、代码补全、多候选对比。
- 不做云端同步、多智能体协作、可视化拖拽装配。
- 不做针对超大仓库的上下文压缩策略。

## 10. 品牌与设计事实

- 品牌无色，信号有色：珍珠白/中性灰阶为底，蓝色只表达“可交互/被选中”。
- 状态色只表达状态：运行青蓝、成功绿、告警黄、失败红。
- 标志 5 个变体：pearl-dark、ink-light、mono-ink、mono-white、app-icon。
- 四条设计原则：视觉即解释、动效承载信息、空间记忆优于面板切换、性能即体验。
- 暗色主题基准 `#0A0A0A`，浅色主题基准 `#F7F7F7`。

## 12. 外部事实（已核实）

- Cordis 是开源插件元框架，插件可挂载、卸载、重组。
- DeepSeek Harness 是官方开发者预览版（内部事实，公开禁用）。
- 当前 Dex 仓库 remote 指向的 GitHub 地址访问返回 404；官网不放置 GitHub 按钮。
- 当前没有 electron-builder 配置，也没有 `.exe` / `.dmg` / `.AppImage` 产物。
