# 六方向与选定三方向

> S=55（2026-10-31 抽样）。
> 网页风格库 20 种：55 % 20 + 1 = 16 → **终端核软未来**。
> 东亚风格库 12 种：55 % 12 + 1 = 8 → **杉浦康平信息曼陀罗**。
> 外观账本为空；无历史项目冲突。
> 六格缩略图：`design-demos/screenshots/thumbs.png`。

## 1. 六个候选卡

### C1 · 观测台 / Instrument

| 栏 | 内容 |
| --- | --- |
| 逻辑与来源 | 最佳设计师：Dieter Rams。少而准、功能可见、仪表化。不是模仿 Braun 的外观，而是“每个读数都有理由”的工作方法。 |
| 借的是什么 | 12 栏网格、发丝分隔线、左侧状态轨、真实读数、蓝色只给操作/选中；产品窗口作为主视觉，不用装饰插画。 |
| 主角素材 | 真实产品截图（聊天 + 3D 图谱 + DAG）+ 自绘状态轨。 |
| 骨架 | 顶栏 → 左文右产品窗口的首屏 → 结构/过程/时间三段纵向诊断 → 架构图 → 性能读数 → CTA。 |
| 胆量花在哪 | 首屏右侧的“正在运行的观测台”：真实界面被切成一条可读的仪表带。 |
| form 来自内容的哪里 | 产品本身就是观测仪器；页面也应该是仪器，而不是营销海报。 |

### C2 · 剖面手册 / Exploded Manual

| 栏 | 内容 |
| --- | --- |
| 逻辑与来源 | 最佳设计师：原研哉。白、空、材料感；信息设计参考 Otto Neurath 的 Isotype 图解传统。 |
| 借的是什么 | 冷白纸面 + 墨黑 + 一点信号蓝；大留白；图号、引线、图注；黑框截图像手册里的插页；无卡片、无阴影。 |
| 主角素材 | 自绘轴测剖面图 + 真实截图插页。剖面图使用产品真实视觉编码：类型=颜色（graph token）、状态=外环、大小=连接度、边=inject / runtime / active run；图层为 L1 模型+调度、L2 工具+技能、L3 会话+沙箱，并注明“type clusters, not physical positions”。 |
| 骨架 | 左竖排刊头 + 右大剖面图首屏 → Fig.01 结构 → Fig.02 过程 → Fig.03 时间 → Fig.04 扩展 → 原则清单 → CTA。 |
| 胆量花在哪 | 首屏把 Agent 拆成一张可读的技术图纸；整个页面像一本印刷的现场手册。图例用 HTML 承担解释，避免 SVG 小字拥挤。 |
| form 来自内容的哪里 | 产品的承诺是“打开黑箱”；拆解图就是最直接的证明。 |

## 2. 选定三张

### 选 C1 · 观测台

- 单看够好：首屏产品窗口 + 状态轨有明确的产品气质。
- 与另外两张不同：暗色、仪表化、产品界面主导。
- 不用力过头：没有把整页做成道具；真实截图承担信息。
- 风险：容易接近常见暗色 SaaS；用 12 栏、细线、读数与真实截图压住。

### 选 C2 · 剖面手册

- 单看够好：浅色纸面 + 大剖面图在一排缩略图里最不一样。
- 与另外两张不同：浅色、印刷、图解主导。
- 不用力过头：拆解图直接服务“打开黑箱”，不是万能隐喻。
- 风险：浅色 + 纸面容易落入“AI 编辑风”；使用冷白、墨黑、信号蓝，不用暖奶油/陶土色。

### 选 C5 · 终端核 → 升级为「一次执行 / Live Run」

- 单看够好：终端窗口与步骤流有明确的技术叙事。
- 与另外两张不同：运动/时间主导，滚动跟随一次执行。
- 不用力过头：只保留“一次 run”这一条时间线，其他段落安静。
- 升级：不只做终端道具，而是把首屏/中段/尾段串成一次真实任务的回放；终端只是入口。

未选：C3（与 C2 同为浅色技术叙事，C2 更独特）、C4（与 C1 同为暗色数据叙事，C1 更贴产品）、C6（朱红墨色与品牌“蓝色只做信号”冲突，且径向图有过头风险）。三张备选保留，用户若想看可随时做成完整版。

### 设计体检

`design_lint.py check`：六个页面无红灯。
黄灯为技术手册/仪表的等宽小标签、结构分隔用的 `·`、真实序列编号；多页样张共享 `public/` 图片是刻意选择（最终 Astro 会自托管资源），因此保留相对路径。

`design_lint.py compare --brand`：三版拉开（骨架相关 0.17 / 0.50 / 0.19）。
不加 `--brand` 时 dir-1 与 dir-3 会因同为品牌暗色底被判「色板几乎相同」；这是品牌约束，不是设计偷懒。三版的骨架与叙事不同：仪表 / 手册 / 回放。

### 交互与响应式

- 1440 与 375 均无横向溢出、无控制台错误、无坏图（Playwright 自动检查）。
- dir-1：暗/浅主题切换会同步替换真实截图，localStorage 持久化。
- dir-3：滚动到 5 个阶段会切换右侧视图、HUD、tick 与状态；点击 tick 可跳转。
- 三个下载页：平台按钮会把平台写入表单；邮箱校验；提交打开 `mailto:` 占位，不伪造成功。
