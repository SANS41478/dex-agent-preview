# Dex AGENT 官网 · 设计 Spec

## 1. 项目

为 Dex AGENT 设计一个 4 页中文官网，面向 Agent 开发者，核心信息是「把 Agent 黑箱打开」。视觉沿用现有品牌体系，但允许比产品界面更外放。

## 2. 输出格式

| 阶段 | 格式 | 尺寸 |
| --- | --- | --- |
| 三方向样张 | 独立 HTML（首页 + 下载页样张） | 1440×900 桌面优先，响应式到 375×812 |
| 最终官网 | Astro 静态站，输出 `dist/` | 同上 |
| 截图 | PNG | 1440×900、1440 全页、375×812 |

最终站无后端、无账号、无数据库。预约表单为 `mailto:` 占位，域名/端点均为占位并写入 README。

## 3. 受众与场景

- 主受众：正在使用插件式 Agent 运行时开发 Agent 的工程师；熟悉 CLI、TypeScript。
- 次受众：对 Agent 内部结构好奇的开发者；不是初学者教程受众。
- 访问场景：桌面 1 米距离为主，移动端为辅；从社交媒体/朋友分享进入，先看首屏，再看真实界面，最后决定预约内测。
- 情感基调：精确、克制、可信、略带锋芒；不是“炫酷 AI 产品”，也不是“企业官网”。

## 4. 核心信息（按优先级）

1. Agent 不该是黑箱；Dex AGENT 让结构、过程、时间都可观察。
2. 三个视角：3D 插件图谱 / 执行流 DAG / 时间线。
3. 不是只读仪表盘：插件热插拔、模型适配器切换、桥接扩展。
4. 为每天 8 小时设计：双主题、布局记忆、键盘、性能、本地优先。
5. 当前 v0.2，开发中；预约内测，安装包即将开放。

## 6. 首页内容结构

1. **Hero**
   - `Open the loop.` 小标 + `Agent 不该是黑箱。` 主标题
   - 副标题：Dex AGENT 把 Agent 的插件结构、执行步骤与工具调用变成可观察、可回放、可扩展的桌面工作台。
   - 主 CTA：下载 Dex AGENT（→ `/download/`）
   - 次 CTA：看它如何工作（→ `#observe`）
   - 状态：v0.2 · 开发者预览 · Windows / macOS / Linux
   - 主视觉：真实产品窗口（聊天 + 图谱 + DAG）
2. **看见结构**
   - 3D 插件图谱；节点/边/状态/交互
   - 真实图谱截图 + 图注
3. **看见过程**
   - Turn → Step → Tool Call；DAG + 时间线；失败传播
   - 真实执行流截图 + 图注
4. **看得见，也改得动**
   - Cordis 插件运行时、桥接层、模型适配器、热插拔
   - 自绘架构图
5. **为每天八小时设计**
   - 双主题、布局/视角记忆、键盘、500 节点基准、本地优先
6. **结尾 CTA**
   - `把回路装进桌面。` + 预约内测

## 7. 观测页内容结构

1. Hero：`观测，不是日志。` + 三个视角 tab（图谱 / 执行流 / 时间线）
2. 3D 图谱：视觉编码表（形状/大小/颜色/边宽/动效）、交互、实时更新
3. 执行流 DAG：Step 节点、Tool Call chip、失败传播、详情面板
4. 时间线与时间旅行：回退、回放、上下文
5. 联动：L1 状态同步 / L2 过滤 / L3 空间导航；一个可点击的示意
6. 性能：500 节点基准 101fps（本机，脚注口径）
7. CTA

## 11. 约束

- 公开页禁用：dsh / DeepSeek Harness / deepseek-harness / 含 dsh 的包名、CLI、profile。
- 允许：Cordis、插件运行时、插件树、桥接层。
- 不编造数据、评价、客户 logo、下载链接、版本号。
- 下载页没有安装包就不出现可下载假按钮。
- 正文 ≥16px，标签 ≥12px，正文对比 ≥4.5:1。
- 无渐变文字、霓虹、emoji 图标、左彩条卡片、假 metric cards。
- 三方向必须骨架不同，不是换色。
