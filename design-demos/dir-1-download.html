FAQ

常见问题

关于产品身份、数据、平台与内测。

Dex AGENT 是官方产品吗？

不是。Dex AGENT 是独立产品，与模型厂商无隶属关系。

数据会上传吗？

本地优先。工作区与会话数据留在本机；只有模型调用会发送到你配置的模型服务。

支持哪些模型？

支持多家模型适配器热插拔，包含 OpenAI 兼容端点。具体模型接入方式会在内测配置说明中提供。

是否开源？

当前仓库未公开，官网不提供源码下载。

需要什么环境？

桌面环境即可（Windows / macOS / Linux）。模型调用需要网络，以及你所配置模型服务的 API Key。

什么时候开放下载？

内测预约开放中，具体时间以邮件通知为准。

可以取消正在执行的任务吗？

当前版本仍在完善任务控制能力，后续版本会补齐。
