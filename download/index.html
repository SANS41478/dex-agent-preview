常见问题。

关于安装、运行时、数据与平台。

Dex AGENT 是官方产品吗？

不是。Dex AGENT 是独立产品，与模型厂商无隶属关系。

数据会上传吗？

本地优先。工作区与会话数据留在本机；只有模型调用会发送到你配置的模型服务。

支持哪些模型？

支持多家模型适配器热插拔，包含 OpenAI 兼容端点。安装后在「设置 → 模型」中填写 provider 与 API Key。

是否开源？

当前源码仓库未公开，官网不提供源码下载；安装包与校验和可从公开 Release 获取。

需要自己安装 Node 或 dsh 吗？

不需要。Windows 安装包自带 Node 与 dex profile，首次启动会把运行环境复制到用户目录。

为什么 Windows 提示未知发布者？

v0.2.1 安装包尚未购买代码签名证书。请从本页或公开 Release 下载，并用 SHA-256 校验文件。

支持 macOS / Linux 吗？

当前 Windows x64 已开放；macOS 与 Linux 仍在准备中，可在预约区留下邮箱。

可以取消正在执行的任务吗？

可以。运行中的会话会显示停止入口；历史会话继续对话走本地控制桥。
