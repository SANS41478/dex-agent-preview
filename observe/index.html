FIG. 01

结构是空间的。

类型 / 状态 / 连接度 / 依赖边

插件不是列表里的一行。它占一个位置，连着几条边，带着自己的状态。图谱让“它由什么构成”变成可以走进去的空间。

  • TYPE颜色 = 类型。模型、工具、技能、调度、沙箱、其他。
  • STATUS光环 = 状态。运行、成功、失败、未激活。
  • EDGE边 = 关系。inject 依赖与运行时调用。

节点大小 = 连接度 / 活跃度。布局稳定，聚焦子图而不是重新排列。

TYPE / 颜色

插件类型

模型、工具、技能、调度、沙箱、其他。颜色来自 graph token，不是装饰。

STATUS / 光环

运行状态

运行、成功、失败、未激活。颜色之外还有环粗与标签文字，三重编码。

SIZE / 大小

连接度

节点越大，连接越多、越活跃。不是随机尺寸。

EDGE / 边

依赖与调用

inject 依赖与运行时调用分开表达；调用越频繁，边越粗。

FIG. 02

过程是因果的。

Turn / Step / Tool Call / 失败传播

Step 是节点，Tool Call 是节点里的证据。失败不是一行红字，而是一条向上传播的路径。点一下失败节点，右侧详情面板给出原因、堆栈、推理文本与工具返回。

  • STEP默认紧凑。序号、状态、一行推理摘要。
  • TOOL工具调用是证据。工具名、入参、返回、耗时。
  • FAIL失败有方向。变红，并向上传播到 Turn。

Step 与 Tool Call 的选中状态会同步到 3D 图谱；折叠面板不会丢状态。

FIG. 03

时间是可回退的。

时间线 / 回放 / 上下文还原

按时间排列事件流，与 DAG 联动。回退到任意 Step，查看当时的上下文；回放一次执行，而不是猜它发生过什么。

  • REWIND回到任意 Step。上下文、工具返回、推理文本都还原。
  • REPLAY重新走一遍。时间线与 DAG 共用同一套事件。

回放不是录屏：它重建的是状态，不是像素。
